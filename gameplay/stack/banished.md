# Banidas

|||{.briefing} [!badge text="Banished" variant="ghost"]
  É a pilha para onde vão as cartas banidas, removidas do jogo permanentemente.
|||
    
Banir uma carta é enviá-la para a pilha de [<span class="main"><b>BANIDAS</b></span>](/gameplay/stack/banished.md), de onde ela não volta para o jogo, a não ser por um efeito que diga o contrário. Quando uma carta é banida, os efeitos [<span class="keyword-timing">Ao Banir</span>](/gameplay/effect.md) dela podem/devem ser ativados.

As cartas banidas ficam de face para cima, mas nenhum efeito delas é considerado.

{.striped}
Configuração | Valor
--- | ---
**Visibilidade** | Face para cima
**Uso** | Nunca
**Afetados** | Todos

# Banidas

{{ briefing `Banished` `É a pilha para onde vão as cartas banidas, removidas do jogo permanentemente.` }}

Banir uma carta é enviá-la para a pilha de {{ banished }}, de onde ela não volta para o jogo, a não ser por um efeito que diga o contrário. Quando uma carta é banida, os efeitos {{ onBanish }} dela podem/devem ser ativados.

As cartas banidas ficam de face para cima, mas nenhum efeito delas é considerado.

{.striped}
Configuração | Valor
--- | ---
**Visibilidade** | Face para cima
**Uso** | Nunca
**Afetados** | Todos

# <span class="summus"> Magisterium</span>

> *Magisterium* é o termo latino para *“magistério”*, no sentido de ensino, autoridade, conhecimento.

Em jogo, o Magisterium representa o estado de maestria de um Herói sobre um determinado aspecto do mundo, seja ele físico, mental ou espiritual. Onde o Herói éterligador combina seu estudo, prática e experiência avançados naquele assunto, com o seu domínio do éter e conhecimento da verdade sobre o universo, levando sua mente a superar os limites esperados do entendimento humano, chegando ao entendimento quase divino e externo, acerca do tema.

Ele é representado por uma carta de {{ class }} na **Zona Extra** da {{ sheet }}, sendo assim, uma {{ class }} adicional especial.

Este entendimento superior é representando em jogo através de bônus. Sendo o Magisterium primariamente um provedor de bônus numérico adicional para o Herói em determinados casos relacionados a sua maestria.

## Regras Especiais

- É necessário ter pelo menos um dos {{ knowledge }} listados na carta de Magisterium no nível **3**.
    - Se em algum momento o Herói perder o {{ knowledge }} necessário (sem considerar o provido pelo próprio Magisterium), ele deve descartar o Magisterium da sua **Zona Extra**.
    - Em outras palavras, o Magisterium só pode ser mantido enquanto o Herói manter um dos {{ knowledge }} dele no nível **4**.
- Quando não estiver em batalha, realize uma **Ação Total** para **Banir** {{ n 5 }} {{ class }} de **Caminhos** que você possua, da pilha de descarte, para adicionar um Magisterium à sua **Zona Extra**.
- Os bônus de **Atributos**, **Conhecimentos**, **Zonas**, etc. proporcionados por um Magisterium são aplicados normalmente como qualquer outra carta de {{ class }}.
- Observando os casos listados na Caixa de Mecânica, quando um deles ocorrer, o bônus de **Mais** é aplicado para o Herói.
    - Os bônus sãos cumulativos, ou seja, se mais de um caso ocorrer, o bônus é aplicado para cada um deles.
- Você pode realizar uma **Ação Total** para descartar um Magisterium da sua **Zona Extra**.

## Adicionais

==- Níveis de Maestria

Os Magisteriums são divididos em dois níveis narrativos de maestria, o nível **Mestre** e o nível **Grande Mestre**, indicado pelo nome da carta, sendo que o nome toda carta de Megisterium começa com um dos dois termos, seguido do tema de maestria.

| **Nível de Maestria** | **Atributos** | **Conhecimentos** | **Slots** | **Efeito** | {.compact}
| --------------------- | ------------- | ----------------- | --------- | ---------- |
| **Mestre**            | +2            | +1                |           | Não tem    |
| **Grande Mestre**     | +4            | +2                | 1         | Pode ter   |

==- Tipos de Bônus

O bônus fornecido não necessariamente é uma constante, em alguns casos pode ser necessário uma ponderação para calcular o bônus.

**Por exemplo:**
- **Bônus Constante:** Ele é sempre o mesmo.
    - *{{ p '+2' }} de {{ dmg }}*
    - *{{ p '+1' }} em **testes***
- **Bônus Variável:** Ele depende de uma variável, como o número de cartas em uma pilha, ou o número de inimigos próximos.
    - *{{ p '+1' }} de {{ dmg }} para cada carta na pilha de descarte*
    - *{{ p '+5' }} de {{ dmg }} para cada inimigo adjacente*
- **Bônus de Dados:** É rolado um dado para determinar o bônus, e o resultado do dado é o valor do bônus.
    - Quando mais de um caso for satisfeito, o dado do bonus é rolado apenas uma vez e aplicado para cada caso, ou seja, o bônus é o mesmo para cada caso.
